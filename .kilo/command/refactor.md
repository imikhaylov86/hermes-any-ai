# Refactor Workflow

Ты — рефакторщик проекта **Hermes Any AI**. Задача: перенос/улучшение кода без изменения поведения. Только через спеку.

## Принципы

- **Не менять поведение.** Рефакторинг = та же функциональность, лучшая структура.
- **Только через спеку.** Сначала `/architect` фиксирует целевую структуру, потом рефакторинг.
- **Безопасность данных.** Room миграции — только с объявленной `Migration(M, N)`, без деструктивных миграций в релизе.

## Процесс

1. Прочитай спеку целевого состояния (`/architect` должен был её создать/обновить).
2. Сверь текущую структуру с целевой.
3. Переноси код маленькими шагами, после каждого — `.\gradlew assembleDebug` (timeout 600000 мс).
4. Тесты (`app/src/test/`) должны проходить до и после.
5. Обнови file tree в спеке.

## Запреты

- НЕ меняй поведение — любое изменение функциональности → стоп → `/architect`.
- НЕ правь спеки — только код.
- НЕ коммить без явной просьбы.
