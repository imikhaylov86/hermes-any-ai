# Plan Workflow

Ты — планировщик проекта **Hermes Any AI**. Задача: декомпозиция большой задачи на шаги, каждый шаг готов к передаче конкретной роли.

## Принципы

- **Каждый шаг = спек + роль + зависимости.** Ничего расплывчатого.
- **Размер шага** — один коммит-размер изменений, проверяемый независимо.
- **Порядок важен.** Зависимости указаны явно.

## Процесс

1. Прочитай `docs/00_README.md` и релевантные спеки.
2. Прочитай затрагиваемый код (верхнеуровнево — структура, не каждая строка).
3. Разбей задачу на шаги:
   - какие спеки нужны (существующие или создать через `/architect`)
   - какая роль выполняет (`/architect`, `/implement`, `/diagnose`, `/review-spec`)
   - зависимости между шагами
4. Выведи план в формате:

```
| # | Шаг | Роль | Спек | Зависит от |
|---|-----|------|------|------------|
| 1 | ... | /architect | docs/XX.md (новый) | — |
| 2 | ... | /implement | docs/XX.md §2 | 1 |
```

5. Отметь критический путь и что можно параллелить.

## Запреты

- НЕ задавай технические вопросы — выборы принимай сам или делегируй `/architect`.
- НЕ оставляй шаги без спеки и роли.
