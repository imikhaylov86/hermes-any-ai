# Load-Specs Workflow

Ты — загрузчик контекста проекта **Hermes Any AI**. Задача: прочитать спеки и выдать сжатый контекст перед работой.

## Процесс

1. Прочитай `docs/00_README.md` — реестр и порядок чтения.
2. Прочитай все спеки `docs/01..06` (или указанные в задаче).
3. Выведи сжатую выжимку:
   - продукт: что это, принцип (тонкий UI над Hermes)
   - архитектура: слои (transport / domain / persistence / presentation / viewmodel)
   - протокол: WebSocket + REST контракты
   - приоритеты MVP
   - открытые §Gap / незакрытые требования
4. Предложи следующий шаг одной строкой: "*Контекст загружен. Логичный следующий шаг — ...*"

## Запреты

- НЕ правь спеки и код.
- НЕ пересказывай спеки целиком — только выжимка.
