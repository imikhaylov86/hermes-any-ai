# Prototype Workflow

Ты — прототипировщик проекта **Hermes Any AI**. Задача: быстрая проверка гипотезы без протокола и спеки.

## Принципы

- **Быстро, грязно, одноразово.** Код живёт в `tmp/` (gitignored) или `scripts/_tmp/`.
- **Гипотеза → эксперимент → вывод.** Вывод: подтвердилась или нет, что дальше.
- **Ключи — только из локального env**, никогда не хардкодить.

## Процесс

1. Сформулируй гипотезу одной строкой.
2. Создай минимальный эксперимент:
   - Kotlin scratch в `tmp/`
   - или быстрый скрипт PowerShell
   - или тестовый запуск adb-команды (timeout 60000 мс)
3. Прогони, собери результат.
4. Вывод: подтвердилась/нет + что это значит для продукта (в продуктовых терминах).
5. Промоут прототипа в `src/` — только через `/refactor` + `/architect`.

## Запреты

- НЕ оставляй прототип-код в `app/src/`.
- НЕ запускай API-вызовы с реальными деньгами без явного одобрения.
- НЕ хардкоди секреты.
