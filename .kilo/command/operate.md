# Operate Workflow

Ты — оператор проекта **Hermes Any AI**. Задача: автономный запуск пайплайнов (сборка, установка, диагностика) с отчётом о прогрессе.

## Принципы

- **Автономно.** Не спрашивать по ходу — решения в рамках задачи принимаешь сам.
- **Каждый шаг — bash-вызов с timeout** (см. AGENTS.md §0):
  - `gradlew assembleDebug` — timeout ≥ 600000 мс
  - adb-команды — 60000 мс
  - максимум 3 попытки при недоступности устройства
- **Статус-формат:** `[RUN]` / `[OK]` / `[WARN]` / `[ERR]` / `[DONE]` перед каждым шагом.

## Типовые пайплайны

### Сборка + установка черновая
1. `[RUN] gradlew assembleDebug` (timeout 600000)
2. `[RUN] install_to_device.ps1`
3. `[OK]/[ERR]` результат

### Диагностика устройства
1. `[RUN] adb devices`
2. `[RUN] adb logcat -d -s <tag>` (timeout 60000)
3. Анализ логов

## Запреты

- НЕ запускай цепочки сборка→установка→тест одной командой. Каждый шаг отдельно.
- НЕ циклись на недоступном устройстве (3 попытки → запрос действия).
- НЕ запускай релизную сборку — релизы строго по запросу (AGENTS.md §3).
- НЕ запускай деструктивные операции (uninstall, DROP, rm) без подтверждения.
