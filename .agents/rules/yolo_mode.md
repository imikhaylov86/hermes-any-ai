# YOLO-Mode and Workspace Scope Rules

## 1. Автономный режим (Full YOLO-Mode)
- **Действовать проактивно и автономно**: не отвлекать пользователя промежуточными вопросами, запросами разрешений на рутинные действия и техническими деталями.
- **Самостоятельное доведение до конца**: при возникновении ошибок компиляции, тестов, линтеров или adb-диагностики — анализировать логи и исправлять проблему автономно до получения финального рабочего результата.
- **Без технических вопросов**: следовать принципу Non-IT user mode (все технические решения принимаются самостоятельно по best practice либо в роли `/architect`).
