# Load Specs Workflow

Универсальный загрузчик контекста. Используй перед началом работы или при переключении домена.

## Процесс

1. Прочитай `docs/SPEC_INDEX.md`.
2. Спроси пользователя в продуктовых терминах: **с чем хочешь поработать сегодня?** (предложи 2-3 варианта по существующим доменам).
3. Загрузи overview домена (`docs/<domain>/overview.md`).
4. Из §9 Related Specs — загрузи связанные спеки (database, feature).
5. Если кросс-доменная задача — загрузи overview всех затронутых доменов + `docs/project_structure.md` §3.
6. Резюмируй **в продуктовых терминах**:
   - Что домен делает (одно предложение)
   - Какие основные действия пользователь может с ним сделать (UI Surface)
   - Какие ограничения сейчас (Gap)
7. Предложи следующий шаг: `/architect`, `/implement`, `/plan`, `/diagnose`

## Правила

- Спеки в `docs/` — **единственный источник правды**.
- Формулы — ТОЧНО как в спеке. Не перефразируй.
- НЕ изобретай параметры, формулы, колонки, которых нет в спеках.
- Резюме — в продуктовых терминах. Не "PG schema X с таблицей Y", а "хранит данные о Y".
